# 3D 月相与月食实验室

网页直接渲染 WebGL，无 iframe、外部库、CDN、图片或网络接口。打开 `index.html` 即可运行，也可用静态文件服务器提供 `index.html`、`style.css` 和 `app.js`。GitHub Pages 从 main 根目录发布。页面初始暂停，设置仅保存在本机。

默认是连续一年：全年总览显示地球绕太阳公转、月球绕地球运动，以及月球轨道交线的缓慢进动。下方局部场景使用随地球移动且对准太阳的参考系，太阳保留在左侧，因此交线的相对方向持续变化。地球位置、月相、交线、月面阴影都由同一个绝对时间计算；月相跨月时不会把地球的位置重置。

参数固定为地球年 365.25 天、月相周期 29.5 天、轨道倾角 5.1°、交线进动周期约 18.6 年。地球按 `earthEpoch - 2π*t/365.25` 转动，局部交线方向为 `π/2 + earthAngle - 2π*t/(365.25*18.6)`。月球相对太阳的轨道角为 `2π*t/29.5`。相对于空间的月球公转方向与地球一致，平均周期约 27.3 天。总览中的交线只缓慢转动，不会随地球公转整圈。

逐次满月按钮由这些固定参数和阴影相交几何生成：扫描每次满月附近的轨迹，找最接近地影时刻，计算是否穿过半影、本影，是否完全进入本影。没有按月份指定某种月食，也没有随机改变轨道。假想起点选在第四轮满月恰好接近交线的方位，不代表任何真实日期或年份。连续运行、全年滑块、下一次满月、逐月按钮、局部月相滑块均共享同一时间。满月与地影接近时自动慢放；基础速度为 120 秒/年。全年播放到末尾停止，可重播。

手动实验另行定格地球，提供普通满月、月全食、月偏食、半影月食的放大对照，可以转动交线。连续一年使用接近真实地月半径比的 Moon/Earth = .287/1.05，手动实验把月球放大到 .77/1.05，便于对比。两种模式按各自半径一致计算月面阴影与近似覆盖比例。全年半影采用较窄的教学光锥，手动实验使用更明显的半影锥；都不是按天体大小及距离实际比例渲染的预测模型。

局部轨道垂直坐标放大 12 倍以看清错开地影。近景和几何月相投影使用未放大的方向，近景阴影坐标偏移回对应的示意轨道位置。阴影逐片元计算，半影渐暗、本影暗红；可见光锥与阴影使用同一参数。覆盖比例为月球圆盘和本影截面的圆交面积近似。关闭阴影锥显示只隐藏示意体积，月面仍计算遮挡。尺寸、阴影和月食所跨示意月龄放大，不可据此估计真实月食时长或日期。日食未模拟。

分步月相讲解保留在折叠区：用三维颜色区分受光半球、朝向地球的半球和两者交集，支持沿地球视线观察，并同步圆盘投影。几何月相亮区不计月食，另列地影覆盖。

`#eclipse` 保留独立的月食放大过程，提供月全食、月偏食、半影月食及避开地影的对照，支持七个阶段、轨迹偏移、播放速度和红光示意路径。该近景固定满月朝向。红月颜色为大气透射光的教学示意，实际颜色随大气变化。

大画面新增“全局：地球公转”，与左上角全年总览共用同一位置、光照和运动模型，并与月面近景同步；支持旋转、缩放、左右转与复位。可以在年度控制栏直接跳到大画面，或分享 `#solar` 链接。局部自由视角、俯视轨道、侧看倾斜和从地球看继续保留。总览大小为教学示意；手动实验定格地球时使用局部视角。月相三步讲解保留原来的折叠位置。
