# 3D 月相与月食实验室

可交互的三维日地月动画，支持旋转、缩放、时间滑块、八种月相和地球观察视角。

网页直接渲染 WebGL，不依赖 iframe、外部库、CDN、图片或网络接口。页面默认为暂停；选择月相后保持选择，球体位置平滑过渡。相机与月相设置只在本机保存。

打开 `index.html` 即可运行，也可以通过任意静态文件服务器提供 `index.html`、`style.css` 和 `app.js`。GitHub Pages 从 main 分支根目录发布。

北半球标准月相朝向。模型中的尺寸、距离、圆轨道和表面纹理为教学示意；月相来自观察角度变化，主动画同步演示地球阴影的遮挡，月食过程另提供放大观察。

分步解释月相：用三维颜色区分受光半球、朝向地球的半球和两者交集，支持沿地球视线观察；同步圆盘投影与轨道观察视线。日常月相教学使用平行太阳光与远距离半球近似。

月食模式提供月全食、月偏食、半影月食及不发生月食的对照；可以调整进程、轨迹偏移、播放速度，并查看七个接触/食甚阶段。分享 `#eclipse` 链接可直接进入月食模式。

阴影为随地球后方距离缩小的本影锥和扩大的半影锥，由示意太阳/地球半径及距离生成。月面逐点判断阴影，半影渐暗，本影用暗红色模拟穿过地球大气的微弱光。体积轮廓与月面阴影使用同一几何参数；圆盘覆盖比例以月球和本影截面的圆交面积估算。为突出阴影，近景固定满月朝向。大小、距离、偏移、亮度和演示时间不对应真实月食预测。

主动画现在把月相和月食放在同一条倾斜轨道：显示地球的本影与半影，月球公转和地球月面近景使用相同位置及逐点阴影计算。可以转动轨道交线，比较普通满月、月全食、月偏食、半影月食；完整公转与满月附近慢放共用月相时间轴。倾角参数 5.1°，垂直坐标放大 12 倍，以便在缩放的教学场景中看清避开地影。月相亮区数值表示未计月食的几何比例，另列本影圆盘覆盖；关闭阴影锥显示只隐藏示意体积，月面仍计算真实遮挡关系。日食未模拟。原有 `#eclipse` 保留为独立放大过程。

轨道场景使用放大的垂直坐标，近景和几何月相投影使用未放大的 5.1° 位置方向。近景阴影坐标偏移到示意轨道位置，使阴影扫过与主场景同步；这是教学缩放模型，不用于预测实际观测时间或精确覆盖范围。缩放的阴影范围使月食段跨越的示意月龄变宽，不能用时间轴估计真实月食持续时间。
